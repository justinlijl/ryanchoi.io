# Ryan Choi profile — GitHub Pages

1. Create a public GitHub repository (or use an existing one).
2. Unzip this package. In the repository, choose **Add file → Upload files**.
3. Drag the contents of the extracted folder into the upload area, including the `assets` folder. Do not upload the ZIP itself. Make sure `index.html` is at the repository root and the files inside `assets` retain that folder path.
4. Click **Commit changes**.
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
6. Return to the Pages settings to find your site link. Publishing can take several minutes.

This is the standalone profile website, with both languages, images, fonts, and social links. GitHub Pages makes the website public. The source folder keeps relative asset paths for a project repository.
